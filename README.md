# Зерно и пепел — концепт-сайт кофейни

Адаптивный промо-сайт для городской кофейни «Зерно и пепел». Главная идея проекта — передать атмосферу уюта, спокойного ритма и маленьких ежедневных ритуалов, сделав выбор кофе простым и понятным для каждого гостя.

## Функциональность и разделы сайта

* **Главный экран и позиционирование.** Приветственный блок с акцентом на философию бренда: понятные вкусы без сложной кофейной терминологии, внимание к деталям и тёплое отношение к гостям.
* **Интерактивное меню с фильтрацией.** Каталог напитков и десертов с быстрым переключением по категориям («Любимое», «Кофейная классика», «По сезону», «К кофе»). Для каждой позиции указаны актуальные цены в рублях.
* **Сезонное предложение.** Отдельный акцентный блок для осенних согревающих напитков с описанием вкусовых сочетаний.
* **Подбор напитка по настроению.** Интерактивный мини-опросник на JavaScript, который предлагает подходящий вариант кофе в зависимости от желаний пользователя в данный момент («Покрепче», «Нежного и молочного», «Чего-то необычного»).
* **Конструктор напитка («Ваша чашка»).** Модальное окно кастомизации заказа, где можно выбрать вид молока (обычное или овсяное с доплатой) и увидеть автоматический пересчёт итоговой стоимости.
* **История бренда и контакты.** Информационный раздел о концепции заведения с заглушкой для будущего адреса и графика работы кофейни.
* **Аналитика и UX-вдохновение.** Дополнительное модальное окно с разбором удачных интерфейсных решений крупных кофейных сетей (Starbucks, Dunkin', The Coffee Bean & Tea Leaf), которые легли в основу навигации и структуры каталога.

## Особенности реализации

* Семантическая вёрстка на HTML5 и адаптивная стилизация на CSS3.
* Интерактивные элементы интерфейса (фильтры меню, модальные окна, подбор напитка и расчёт стоимости) реализованы на нативном JavaScript.
* Предусмотрена корректная обработка состояния при отключённом JavaScript.

## Статус проекта

Демонстрационный прототип интерфейса. Функции онлайн-оплаты, оформления заказов и программа лояльности заложены в архитектуру, но на текущем этапе не активны.
